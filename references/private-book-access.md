# 私有书库按需只读核对

随包知识始终可独立运行。只有当前用户授权、运行环境能访问其私有 GitHub 仓库，且确实需要核对原页时，才启用本连接；不能把仓库链接或公开技能当成访问授权。不要把个案聊天、截图、身份或财务信息发送到 GitHub 搜索、Issue、日志或书库。

## 连接条件

在使用设备上由仓库持有人配置 `XIAONANHAI_BOOK_REPO=owner/repository`，并为 GitHub CLI 登录具有该仓库读取权限的账户；不把令牌、仓库标识或本机路径写进公开技能、提交记录或示例。建议使用仅对该仓库具有 Contents read 权限的凭据。脚本只调用 GitHub GET 接口，**这不等于当前账户本身被限制为只读**。如 `gh` 不在命令搜索路径，可在当前设备设置 `XIAONANHAI_GH` 指向它。运行脚本还需 Python 3 和 `pypdf`。

先用 `python scripts/read-private-book.py --list` 查精确文件名，再按场景指定 `--book '文件名.pdf' --pages 12-13`。脚本读取私库清单，核对目标 PDF 的大小与 SHA-256，仅输出请求的 PDF 页文字；不克隆仓库、不写原书副本。**每次仍会把目标整份 PDF 从 GitHub 传入内存**，所以它不是零下载或零数据传输；模型读取页文字时，该模型服务也会处理这些摘录。图像、扫描页、OCR 缺失和译文问题需另行核对，不能把空文字层当书中没有内容。

## 失败回退与跨设备边界

私库 404、无权限、缺 GitHub CLI／Python／`pypdf`、清单不匹配、PDF 页超范围或宿主不支持执行工具时，停止远程读取，直接使用随包已核条目并标明“本次未查原书”。不猜测私人仓库内容，不要求用户把凭据贴到聊天里。仅有 GitHub 文本连接器不代表能解析私有 PDF；不同模型、手机端和新设备都需要各自被授权的访问方式。公开技能的所有使用者不会因安装技能而获得私库权限。

读取成功后记录文件名、当前 PDF 页码、哈希和适用语境，区分原书观点、技能改写和用户个案事实。仅为当前问题取用必要页段；不整书输出、转存到公开仓库或为个人档案建立缓存。
