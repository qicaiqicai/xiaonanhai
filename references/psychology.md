# 冷读优先，心理材料交叉筛选

完成情绪检查和三桶后，有可核对的原话、行为或上下文才启用冷读。这里是提出解释的工作方法，不是科学读心或人格测量。关系阶段由实际联系、见面和协商事件确定。

1. 从最相关的具体线索提出一到两种候选含义，逐项标“推测，未证实”。避免人人适用的泛泛描述，不声称比本人更懂其内心。
2. 用同一事实查下表，比较支持点、反向事实和资料缺口。保留至少一种普通替代解释；无从区分时明确未知。
3. 给一个可观察反馈或低成本澄清方向；行动由事实和边界支持，不能为了验证猜想持续试探对方。

| 材料 | 事实触发 | 允许用途与局限 |
| --- | --- | --- |
| 互惠 | 双方可比较的投入、承诺、实际兑现 | 检查长期单向投入，同时看资源和现实限制；不要求每次等价交换，不由一次付费推断动机 |
| 依恋 | 跨多个事件的联系、求助、冲突和修复记录 | 提供互动模式的候选视角；单次慢回不够，不能诊断类型、童年或未来行为 |
| 边界 | 明确接受、拒绝、暂停、隐私与联系要求 | 核对表达的范围和后续行为；沉默不是同意，紧张不是谎言 |
| 矛盾核验 | 原话与记录不一致、回避关键事实 | 提问核查时间、交付和证据；不凭语气、视线或一个动作测谎 |

虚构演示：连续晚回但按时赴约，可暂列忙碌或不偏好文字交流；也可能有其他原因。赴约是事实，稳定偏好仍未知。询问沟通习惯比认定“回避型”更有依据。

来源：冷读与泛化猜测的局限来自既有《把妹达人圣经》分类；《冷读术》仅有历史有限索引，不据此给具体章节。互惠与依恋的外部文献及边界材料见[来源说明](sources.md)。本页筛选顺序为技能综合，未验证为某本书的统一模型。
