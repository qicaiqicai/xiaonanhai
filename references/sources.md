# 来源、覆盖与可选原书核对

公开包是既有知识分类的简要转述和项目工作规则。它不包含原书、逐页摘录、私人资料或私库访问方式；不声明全部书籍已核验，也不作为原书替代品。书籍作者的解释与效果主张不等于独立科学证据。

| 知识主题 | 既有整理所参照的书籍 | 本包取用与限制 |
| --- | --- | --- |
| 真实表达、生活建设与自主选择 | Models／《魅力模型》、《阿尔法吸引》 | 提炼为真实目标和可持续生活；不推广性别刻板结论 |
| 聊天、分享、邀约与成本 | 《聊天游戏》《约会很糟，但你并不糟》《把妹百科泉书》《绝密话术》 | 提炼为具体话题与现实安排；原书阶段不同，不拼成共同理论 |
| 文字推拉与趣味 | 《逆向恋爱术》 | 取真实兴趣与轻松转折；关于故意撤回必然吸引的断言未获验证 |
| 冷读与反馈校准 | 《把妹达人圣经》；《冷读术》仅历史有限索引 | 提出可核验假设，不声称识透人格；未核章节不引用 |
| 倾听、互惠与停止投入 | 《恋爱宝典》系列、《让她神魂颠倒》《迷上我》 | 等待和重试主张存在冲突，不设置统一小时数或尝试次数 |
| 言语矛盾与核验 | 《识破谎言》 | 只取记录比对与具体提问，不从单句诊断欺骗 |
| 成人沟通与反馈 | 《她先来》《多重高潮的男人》《如何整夜做爱》 | 只取沟通、反馈与边界主题；医学、效果及传统练习未验证 |

《诱惑的艺术》《欲望的演化》等既有阅读仍有范围缺口；本包不提供其全书路线，不据目录补写内容。《What Every BODY is Saying》等书籍未核段落不作已读来源。书籍版本和译本差异仍可能影响理解。

## 外部材料

- Gouldner, “The Norm of Reciprocity” (1960), [DOI](https://doi.org/10.2307/2092623)。使用范围为互惠概念，不是投入必须相等的量表。
- Hazan & Shaver, “Romantic Love Conceptualized as an Attachment Process” (1987), [摘要](https://pubmed.ncbi.nlm.nih.gov/3572722/)。群体模型不支持凭聊天诊断个人依恋类型。
- CDC, [健康关系教育材料](https://stacks.cdc.gov/view/cdc/127878/cdc_127878_DS1.pdf)。借鉴空间与隐私边界概念；材料主要面向青少年，不当作商业规则或成人诊断工具。

以上保留既有整理的出处，并非本次发布重新完成文献或整书核验。需要具体章节或引文时，必须取得有权访问的相应版本再核对；否则只标为随包概括。

## 持有人可选的本地核验

普通使用者无需原书。持有人明确指定已获授权的本地文件和核对范围后，才读取相关段落；不扫描书库、不索取令牌、不自动联网获取。私人文件只辅助当前核验，禁止转发、上传或复制到公开仓库和回答中供他人查阅。公开输出仅保留可公开的必要概括与正常书目归属，不提供私人来源路径、链接、摘录或下载方式。

内容更新逐条去重，保留作者冲突和覆盖缺口。具体页码只在核对同一版本后使用；所有公开示例均为新写的虚构演示。原创规则的公开许可不授权第三方原书。
