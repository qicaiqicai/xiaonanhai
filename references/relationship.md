# 关系阶段与现实行动

六阶段是检索导航，不是必经等级。每次关系咨询选唯一主阶段，信息不足标暂定；长期协商可以从任何相关阶段进入。商业场景不套此表。

| 阶段 | 事实定位 | 本轮动作重点 |
| --- | --- | --- |
| Phase 0 准备 | 当前主要问题是生活、目标、表达或社交准备 | 真实生活建设、个人底线、可执行练习 |
| Phase 1 线上联系与邀约 | 正在平台聊天、表达兴趣或协商首次见面 | 具体接话、相称分享、低负担邀请 |
| Phase 2 见面与相处 | 已有双方确认的安排或已实际见面，注明筹备／已发生 | 时间地点预算、现场交流、收尾与跟进 |
| Phase 3 亲近沟通 | 正在表达或讨论具体亲近意愿 | 核对当时意愿，观察反馈，随时停止 |
| Phase 4 私密相处 | 成年双方自愿讨论或接受私密安排 | 具体边界、双方体验、退出自由；空间不代表后续行为许可 |
| Phase 5 长期协商 | 明确讨论排他、联系、时间费用或未来期待 | 区分协商中／已共识，检验实际承诺 |

## 邀约结果

| 事实 | 主动作 | 反馈与停止 |
| --- | --- | --- |
| 未接受本次时间或活动 | 接受本次结果 | 原因未知；新互动与可行安排出现后才考虑新邀请 |
| 主动提出替代时间 | 核对自己日程和地点 | 双方确认后再预订 |
| 仅说改天，无日期 | 记录未落实 | 不推定意愿不足，也不当作承诺 |
| 已约定但提前取消 | 处理行程与订单 | 看实际通知时间和成本，不把已通知写成无故爽约 |
| 已约定但未到、未通知 | 必要时一次核对，达到本人等待上限后离开 | 原因未知；今后变动提前通知，减少不可退预付 |
| 明确别再邀请／联系 | 按表达范围停止 | 不换活动、账号或渠道绕过 |

首次或前期见面优先公共、交通方便且能独立离开的地点，预算与费用安排先说清。只有口头意向而细节未定时，先确认；双方早已确认的安排不能仅因未回二次确认就擅自宣布取消，需根据实际约定及时说明自己的安排。付款不换取亲密或关系承诺。

## 见面与修复

现场从共同情境自然交谈，冷场可换话题或自然收尾。变更地点、活动和亲近程度先提出具体选择，依据实际同意行动；散场按真实日程，后续有真实内容就联系，不设固定失联时长。

误判后核对具体事实与影响：不清楚用澄清；自己确有错误则具体道歉并落实补救；时间地点不合则协商调整。虚构演示：“我把时间记错了，耽误你了。预订我来处理，是否改期由你决定。”不要求对方因道歉而原谅或再见。

接受道歉和愿意继续交往分别记录。对方愿恢复互动就正常接续并改进行为；明确不愿再见就停止邀约；没有回复只记录未回复，已承诺的退款或归还仍需落实。同类问题再次发生时检查具体承诺、影响与可执行变化，不机械按次数定性。

## 长期关系

逐项协商联系频率与独处、关系定位与排他、费用时间分担、承诺落实、反复冲突。双方明确同意后才记为共同约定；不同投入方式不自动意味着不公平。若核心期待无法同时满足或达到本人明确成本上限，停止相关承诺并处理物品、费用等现实事务。朋友关系同样需要双方愿意。

每个方案写明事实触发、现在做什么、实际时间节点、观察行为、条件备选与停止哪项投入。来源是项目综合与既有书籍分类，非某书统一流程，见[来源说明](sources.md)。
