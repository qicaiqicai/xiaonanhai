# 书库蒸馏：判断模型与即时动作

本页把已读书目的可用**思考方法**压成检索入口，不替代[书源动作路线卡](book-route-cards.md)和[来源说明](sources.md)。页码沿用当前 PDF 副本此前的有限核对记录；本次蒸馏没有重新核对原书。作者叙事、统计和效果解释不等于现实中的因果证据。先看当前原话与行为，再选模型；不得用书名推断一个人的动机。

## 四个可迁移模型

| 模型 | 怎样使用 | 来源锚点与适用边界 |
| --- | --- | --- |
| **原话接点 → 本人真实贡献 → 新反馈** | 从对方实际说出的细节接一句，补本人真实经历或态度，留自然接话口；若对方换题就跟新题。可用于初识聊天，也可用于见面时避免连续盘问。 | 《浪迹科教〈从1到N〉典藏版》PDF 117–146；《米豪方法》37–39、56–74；《迷上我》191–210；《如何避免孤独终老》146–166。接话不证明好感；书中残缺聊天图不作原句模板。 |
| **表达 → 确认 → 兑现** | 把“说过想见”“定下时间地点”“实际赴约”分开记录；状态改变时确认当前安排。可用于邀约与长期关系，也可用于商务协作。 | 《中国把妹达人》PDF 218–220；《把妹百科泉书》112–118；《如何避免孤独终老》190–200、259–290。书中案例只提示核查问题，不能证明某种心理机制；商务责任另核合同与凭证。 |
| **当前互动与长期适配分层** | 一次热烈、冷淡或亲密仅更新当下互动；长期决策另看双方明确目标、现实约束、协商及持续行动。可用于刚见面后的下一约，也可用于排他、距离或费用协商。 | 《中国把妹达人》PDF 185–196；《如何避免孤独终老》81–100、167–220、248–290；《浪迹科教〈从1到N〉典藏版》229–236、263–294。群体说法、着装和单次回复不能给个人定型。 |
| **具体差异 → 单点核对 → 可逆投入** | 当叙述与记录不合，先列出金额、时间、用途、承诺或交付的差异，只问一个可核问题；核实前控制新增成本。可用于借款、合作，也可用于关系中的实际费用。 | 《识破谎言》PDF 37–63、82–103；《陈昌文〈恋爱宝典1〉》PDF 110。偏题或说法不一不自动证明欺骗；法律和财务结论需另有可靠材料。 |

这些模型满足跨情形复用，但只是**判断与行动框架**，不是经实验证明的吸引规律。固定聊天轮数、回复延迟、“撤回必然吸引”、一句反驳就是“考验”、身体语言读心以及单书评分，降为待核作者主张，不当作跨场景模型。

## 事实触发的动作规则

1. **只有共同场景** → 用眼前真实活动开场，留一个易答的口；她补新细节就跟进，持续短答则暂停连问。参《泡学惯例军火库》PDF 4–20；《骄傲与风趣指南》40–54。
2. **聊天变成问卷** → 补一段贴着当前话题的本人短经历；她延展就继续，换题就跟题。参《绝密话术》PDF 6–8；近同源《聊天话术终极指南》1–28，两者不算独立效果证据。
3. **带笑的调侃或挑战** → 先答她原话，再用认可加轻反转；她认真纠正就直答。参《米豪方法》PDF 24–25、35–41；《骄傲与风趣指南》95–114。
4. **分享兴趣、成就或烦恼** → 接她强调的一个细节，再给相称的真实回应；若是诉苦，先看她要倾听还是讨论办法。参《浪迹科教〈从1到N〉典藏版》PDF 125–146、367–368；《迷上我》191–210、254–278。
5. **共同兴趣且有真实可兑现安排** → 提议具体活动、时间和双方方便离开的地点；接受则确认，给替代时间则协调，“改天”只记未确认。参《米豪方法》PDF 96–108；《让她神魂颠倒》60–62。
6. **已确认计划，后来语气变冷** → 先核计划是否仍成立；自己漏确认则承认疏漏，提一次清楚重排。参《中国把妹达人》PDF 218–220；语气不能覆盖已达成的安排。
7. **联系频率起争执** → 对照多次实际联系与作息，商量可兑现节奏，再看执行与修复；不凭单次晚回诊断依恋类型。参《依恋》当前 PDF 7–204；《聊天话术终极指南》24。
8. **钱款或交付说法与记录不合** → 指明一个具体差异，核对可留存材料；未核实前不增加不可逆投入。参《识破谎言》PDF 37–63、82–103；《恋爱宝典1》110。

即时接话只选一条最贴近原话的规则，先给**一条**可发句；复盘时再展开三桶、三个角度和后续分支。规则的作用是提出下一步与观察点，不保证对方按预期回应。

## 保留分歧，而非混成定律

| 分歧 | 当前选择方法 |
| --- | --- |
| 固定等待 vs 及时回复：《聊天游戏》PDF 164–175、223–226、283–286；《让她神魂颠倒》60–62；《恋爱宝典4》79。 | 有约定或时限先及时确认；其余按本人真实可用时间和对方实际互动，不造最佳分钟数。 |
| “考验” vs 实际问题：《米豪方法》81–90；《泡学惯例军火库》58–69；《女人考验男人时想要什么》122。 | 按原话区分玩笑、请求、不同意见和拒绝；先答实际问题，玩笑才接梗。 |
| 明确意图 vs “朋友框架”：《聊天游戏》91–96、114、141、159、273–284；《让她神魂颠倒》46–48、60–62。 | 对方直接问为何接近时，真实说明当前兴趣和愿意如何了解；尚无双方共同期待时，不假装已经是朋友或已有关系。 |
| 故意撤回 vs 正常接续与修复：《逆向恋爱术》68–79、144–154；《诱惑的艺术》136–137、399、538–539；《浪迹科教〈从1到N〉典藏版》299–319。 | 先核具体错误、安排与反馈；自己失约要修复。作者关于撤回引发追逐的主张有书内反例，不保证结果。 |
| 身体线索 vs 明确表达：《让她神魂颠倒》31–33、54–55、63–64；《把妹百科泉书》198–199；《欲望的演化》15、193–204。 | 非语言反应只提示当前舒适度，不替代具体意愿；线上调情与线下身体行动分开判断。 |

## 表达与检验边界

对用户先说**现在能做的一件事**，用接近原聊天的语气写句子；若要解释，只点出原话、下一轮看什么。复盘可给理由、替代解释、成本与停止点，但不冒充读心，不用“高框架”给平等协调贴负面标签。这个技能能整理候选行动，不能预测具体女性、合作方的想法或保证推进成功；缺图、错行、译文及书中研究效力仍以[来源说明](sources.md)和私有台账记录为准。
