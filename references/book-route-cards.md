# 书源动作路线卡

按**当前已发生的原话或行为**选卡；书名用于追溯思路，不用于判断对方人格。下列页码是此前对当前 PDF 副本的有限核对位置，不保证其他版本同页。每张卡都是技能改写，不是原书引文，也不保证效果。通用三桶和四维判断仍按[判断流程](workflow.md)执行。

| 事实触发 | 来源路线与本次可用动作 | 下一轮观察与停止点 |
| --- | --- | --- |
| 用户想破冰，但没有可借用的私人信息 | 《泡学惯例军火库》PDF 4–20 页、《骄傲与风趣指南》PDF 40–54 页：从双方眼前的活动、公开内容或真实共同场景切入，说明为何搭话，留一个容易接的口。前者是多人话术汇编，后者的七段路线也并非必经阶段。 | 对方接话就接她新增的细节；短答或忙碌就结束这一轮。不把礼貌回应当兴趣证明。 |
| 互动变成一问一答，仍有双向回应 | 《绝密话术》PDF 6–8 页与近同源的《聊天话术终极指南》PDF 1–28 页：用“融洽、安全、联系、深入、邀约”检查当前缺什么；补一条与当前话题有关的真实短经历，不按五段强制通关。 | 对方补充细节就继续该线；转题就跟随新题；没有接话就暂停连问。两份近重复文本不算两项独立效果证据。 |
| 对方友好接梗，用户想制造轻微张力 | 《米豪方法》PDF 24–25、35–41 页与《骄傲与风趣指南》PDF 95–114 页：先接住原话，再用“认可＋轻反转”或明显是玩笑的共同想象，末尾留可回应的口；不得把玩笑写成真实履历。 | 她继续玩笑可再接一轮；她认真纠正就直答；她不适就收回玩笑。两书都含故意冷落等相反做法，这里不把它们当吸引规律。 |
| 对方谈具体兴趣、经历或压力 | 《米豪方法》PDF 37–39、56–74 页；《骄傲与风趣指南》PDF 171–181 页：抓住她自己强调的一个细节，回应后分享相称的真实经历。倾诉本身不等于邀约或亲密意愿。 | 看她是否追问、分享或改变话题；按新内容调整。本人无力承接时可如实说明，不假装理解全部感受。 |
| 已约见，担心冷场或行程僵硬 | 《让她神魂颠倒》PDF 20–29、36–46 页：准备一个双方认可、预算可承受的基础活动，另备可选延伸；围绕共同活动接话，穿插真实短故事。它的 20 条规则是主题集合，不是固定顺序。 | 约会中询问是否愿意延长；若不愿，正常结束。活动体验不证明对身体接触的意愿。 |
| 想表达欣赏，又担心过分迎合 | 《让她神魂颠倒》PDF 46–50、60–62 页及《骄傲与风趣指南》PDF 162–170 页：直接指出对方已展示的具体趣味或能力，并说明自己的真实兴趣；保持原有生活安排。 | 对方积极回应可继续聊或提出可兑现邀约；只有礼貌回复时不补造兴趣。表达喜欢本身不等于失衡讨好。 |
| 用户想把线上互动转成见面 | 近同源的五阶段聊天路线 PDF 6–8 页、《米豪方法》PDF 96–108 页、《让她神魂颠倒》PDF 60–62 页：用双方确实聊到的兴趣提出时间、公开地点和活动；接电话先问是否方便。 | 接受则确认安排；冲突并给替代则协调；“改天”但无安排只记未确认；明确拒绝就结束本次邀约。不使用书中固定轮数或等待时长。 |
| 用户把不赞同、调侃或认真提问统称“考验” | 《泡学惯例军火库》PDF 58–69 页承认对方未必故意测试；《米豪方法》PDF 81–90 页同时提出玩笑与冷处理两线。先按原话分为可接玩笑、实际问题、明确边界：分别轻松接梗、直接答题、停止当前方向。 | 看对方是否继续玩笑、补充具体问题或要求停下。不能用“废测”标签跳过实质问题或拒绝。 |
| 男方希望练习，而非只求一条话术 | 《阿尔法吸引》的 33 条规则、《把妹达人圣经》当前合订本 PDF 18–194 页的训练部分：先定本人目标，再挑一个可控练习（仪表、声音、真实开场或讲述），记录实际尝试和反馈。两书均有作者评分／阶段，不是对对象的测量。 | 复盘具体行为有没有改进；不要以一次回应推断个人价值。合订本 PDF 196–314 页的自述故事反而显示短期技巧不能替代长期投入。 |

## 从初识延伸到长期决策

| 事实触发 | 来源路线与本次可用动作 | 下一轮观察与停止点 |
| --- | --- | --- |
| 交友软件上可选对象很多，用户迟迟不愿尝试 | 《如何避免孤独终老》当前 PDF 41–50、104–145 页：先写本人最低可接受条件及真实兴趣，再选本人也愿参加、能自然交流的活动；线上从公开资料的具体细节接话。作者的“37%”与平台数字不直接决定现实选择。 | 记录自己实际参加、发出或回应的互动；不能从一次没回应判定人或平台。选择成本由本人决定，不用书中的月份和比例作期限。 |
| 首次见面像互相面试、连续追问 | 同书 PDF 146–166 页区分支持回应与把话题抢回自己的回应；《让她神魂颠倒》PDF 24–28 页也建议共同活动。顺着对方刚说的具体细节追一层，再分享自己的相关经历。 | 对方愿意延展就继续；转题、疲惫或时间到便自然收尾。回顾双方体验，而非只数问答次数。 |
| 关系里因回复慢或独处时间争执 | 《依恋》当前中文 PDF 7–204 页可用作互动模式的候选视角；《聊天话术终极指南》PDF 24 页另提私人空间。先核对多次联系、求助和修复记录，再说明双方实际作息，协商可兑现的联系习惯。 | 看约定是否执行、冲突能否修复；单次晚回不诊断“回避型”，也不由作者模式填补对方内心。 |
| 长期交往前出现费用、目标或承诺分歧 | 《陈昌文〈恋爱宝典1–4〉》多本问答重复谈现实条件、投入、邀约及止损：核对已说目标、实际付款、时间投入和已兑现的安排，再进行一次具体协商。系列中的“筹码／交易”是作者世界观，不能给个人定价或推断动机。 | 看对方是否明确答复与实际落实；若仍无法协调，男方可选择减少自己的投入。书中不一致的等待期限不是统一规则；钱款和法律责任须另核凭证与现行资料。 |
| 用户想凭“诱惑者类型”或经典故事设计互动 | 《诱惑的艺术》当前 PDF 34–155 页有九种作者形象，其中外观、风格、具体倾听、兑现帮助可作为自我表达检查；历史、电影和小说故事不是个人心理证据。先只借本人真实能长期维持的风格与具体行动。 | 看当事人是否享受当前互动及自己是否能兑现；不扮演角色，不从她的表情或童年猜她“缺什么”。 |

## 用书中案例检验误判

| 事实触发 | 来源案例与本次可用动作 | 下一轮观察与停止点 |
| --- | --- | --- |
| 已答应活动，男方却因随后一句冷淡回复而不确认 | 《中国把妹达人》当前 PDF 218–220 页同一事件含男女双方不同叙述：对方已接受看电影，男方把后来语气读成否定，未按约确认。先核对**既有安排是否仍成立**；若自己漏确认，承认具体疏漏并提出一次清楚的重排。 | 看她是否重新确认或另给安排；没有答复只记未落实，不倒推“她在考验”。书中双视角仍非独立验证。 |
| 暂时热烈，男方想立即判断长期承诺 | 同书 PDF 185–196 页记录短暂升温后并未稳定发展，作者也反省自己曾用“对象类型”解释分开，却忽略现实处境。先说清本人短期或长期目标，询问她明确的期待，再看可持续时间、距离和实际约定。 | 以持续兑现与分歧协商校准，不凭衣着、慢回或单次热情给人定型；本书 PDF 194 页所指模型图在当前副本缺失。 |
| 取消后重新相约，用户想证明“先前拒绝是假” | 《把妹百科泉书》当前 PDF 112–118 页的作者单方叙事记录一次取消及后来对方主动重开邀请。把两件事按时间分别记录：先前未成，后来出现新邀请；按新安排确认。 | 后来的主动并不能证明前次取消的原因。若新安排再次改变，核对通知和成本；不凭作者案例推定本案会重约。 |
| 赴约后原定场所关闭或活动不合适 | 《把妹百科泉书》当前 PDF 153–162 页的叙事有事前备选和餐厅打烊后的临场改找；可先核实时营业、交通和预算，再给对方一个便于拒绝的公开地点备选。 | 对方愿意改去就确认新地点；不愿或时间不足就正常结束。事前考察也不能保证当天营业，不能把计划落空解读成对方态度。 |
| 约会中自己说了冒犯的话，随后又收到积极邀约 | 同书 PDF 107–111、119–125 页同时出现职业贬损、后来互动以及不同接触节点的拒绝。就冒犯的具体话承认影响并简短道歉；把继续约会、当下接触和关系目标分开询问。 | 对方接受道歉可恢复普通交流；抽手、躲开或要求别拉她时停止该动作。后来继续见面不倒推此前玩笑合适，也不取消当下限制。 |
| 旅行或异地相处很热烈，却出现陪伴与关系期待分歧 | 同书 PDF 194–202 页记录住宿需求、工作安排冲突、希望慢一些与认真交往的表达。先说明本人能兑现的时间及关系意图，再分别协商下次见面和联系节奏。 | 看实际安排是否落实、双方能否接受距离成本；目标不能对齐就停止增加承诺。旅行中的热烈和住宿求助都不能替代关系协商。 |
| 用户拿小说里的成功情节当现实证据 | 《全民情敌》当前 PDF 第 4 页已标明虚构；PDF 121–127 页一段连续“她会如何回应”的夜场预演，最后揭示现实只是一句告别。把预演与实际行为分桶，只从真实反馈决定下一步。 | 预演不能证明某种推拉奏效；小说里的酒后、拉扯或旁人劝离也不构成继续接触的许可。当前 PDF 660–661 页所指画面缺失，不补造。 |

## 相近书目之间的执行分叉

**直接追问来意时的分歧：**《聊天游戏》当前 PDF 91–96、114、141、159 页强调说明互动目的，273–284 页又建议用“朋友框架”降低期待；《让她神魂颠倒》PDF 46–48、60–62 页主张直接表达兴趣。若对方问“你为什么接近我”，按真实情况说明兴趣和愿意如何了解，不把尚未建立的关系说成既成朋友。她愿继续交流就接具体话题；只愿普通社交就尊重该范围；明确不想继续就结束本次方向。这是书内路线分歧，不是保证效果的统一话术。

| 事实触发 | 来源路线与选择依据 | 下一轮观察与停止点 |
| --- | --- | --- |
| 男方想建设自己的社交生活，却只在搜集话术 | 《魅力模型》当前 PDF 101–119、126–130、199–215 页的作者链条为真实生活→面对开场焦虑→表达真实意图；选本人愿持续参加的活动，再做一次短介绍、接对方一个话题点、分享相称经历。与《坏蛋之道》PDF 6–9、56–64 页的目标和渐进练习相通；后者有信念训练和更强的角色主导说法，不能替代真实反馈。 | 看自己是否实际参与、双方是否接话；若活动不适合自己的日程和预算，换活动。书中的陌生搭话秒数与“男方必须主导”不是通用条件。 |
| 刚认识的她只回短句，但尚未拒绝聊天 | 《浪迹科教〈从1到N〉典藏版》当前 PDF 117–124 页作者给六步聊天法：短招呼→真实可接内容→短答时低负担再核对→说明见面缘由与活动→轻量邀约→确认安排。选当前能用的一步，不要求走满六步；《迷上我》当前 PDF 171–190 页则侧重抓原话关键词，回应情绪后添本人相关经历。 | 她补新信息就沿新话题接；持续短答或无回应就暂停这一轮。两书的百分比、固定联系期限和“短答一定有隐藏心理”都不能用于本案。 |
| 她提新话题，男方仍在单方面讲解旧话题 | 《浪迹科教〈从1到N〉典藏版》当前 PDF 125–146 页批评忽略对方新增细节；用“关系深浅→她实际说了什么→本人想回应哪个点→选自然措辞”的四层问题切换。当前版聊天图残缺，不能照搬具体来回。 | 她继续分享就接下一条具体细节；若问的是实际问题先回答，不强行扯回暧昧。 |
| 一句明确邀约已有时间敏感性，男方想按固定规则故意晚回 | 《聊天游戏》当前 PDF 164–175、223–226、283–286 页主张多个固定等待数值，却也说当天见面须及时确认；《让她神魂颠倒》PDF 60–62 页反对人为等数小时；《恋爱宝典4》PDF 79 页又主张对等等待。按本人真实可用时间及约定截止点回复。 | 看实际计划是否确认和兑现；若因延迟误事，及时修复。三种互相冲突的作者主张不合成“最佳分钟数”。 |
| 男方想用群体偏好推断当前女性的长期目标或性兴趣 | 《欲望的演化》当前 PDF 15、33–34、50–62、134–157、193–204 页区分目标、情境、相容性和持续兑现，并提醒微笑与眼神可能被过度解读。先问本人要短期还是长期，再听她自己表达的目标；长期看可靠、善意和实际约定。 | 她明确表达与落实什么就记什么；没有表达的目标仍未知。作者群体统计和演化解释不能给个人评分或替代具体同意。 |
| 对方提建议、请求或玩笑，男方急于按“废测”反打 | 《女人考验男人时想要什么》当前 PDF 122 页与《泡学惯例军火库》PDF 58–69 页的可用共同问题是：这句话究竟是玩笑、具体请求、不同意见还是边界？先答内容再决定是否轻松接梗。不同意见不等于已确认约定失效；约定未落实要另核事实与成本。 | 她继续玩笑再玩笑；补充实际需要就处理需要；不想继续就停止当前方向。不要把一切不同意见解释为性别测试。 |

## 同系列问答的不同触发点

《陈昌文〈恋爱宝典1–4〉》反复使用“筹码／交易”比喻；以下仅按各册已读问答保留**不同的现实问题**，不把比喻变成对人的价格或动机判断。案例是作者收录的叙述，未独立核实。

| 事实触发 | 当前副本位置与可用问题 | 下一步与限制 |
| --- | --- | --- |
| 借款口述与记录不一致，或争吵后急于判断关系 | 《陈昌文〈恋爱宝典1〉》PDF 110 页有债务说法与征信记录不一致；80–95 页有听完、留表达空间的沟通主题。先把金额、用途、原约定、记录和双方原话分开，再问一个具体差异；情绪争执先听清问题。 | 能核记录就修正事实；不能核就暂缓钱款决定。单方说“她只图钱”不进事实桶，现行借贷责任另核。 |
| 邀约与家庭、贷款或照护责任缠在一起 | 《陈昌文〈恋爱宝典2〉》PDF 101–102、163–210 页问答触及费用时间、子女照护与贷款；先核谁已承担什么、下一步需谁同意、是否有书面责任。 | 用真实安排协商，无法负担就说明上限；不要从职业、收入或生育选择推定人格。涉及贷款签署和监护要另查适用资料。 |
| 初识后未回、真实展示与婚前财产期待混在一起 | 《陈昌文〈恋爱宝典3〉》PDF 105–113、210、231–232 页分别谈联系、具体活动与财产期待。先用一次真实活动或直接问题核对当前安排；财产问题则单独书面澄清。 | 看具体接受、实际付款和兑现；无回应不持续追加高风险投入。作者的反复联系和“让人离不开”不作为成功证据。 |
| 异地、礼物或顺路邀约影响双方成本 | 《陈昌文〈恋爱宝典4〉》PDF 99–103、108–118、195、206–209 页涉及真实故事、礼物、费用、异地与“顺带”见面。顺路只有实际属实时才说；先核交通、预算、双方时间与礼物是否被附加条件。 | 接受就落实安排；取消则看具体通知和成本；反复索财但用途不清时暂停支出。礼物不换取关系，照片或晚回不证明内心。 |

## 《诱惑的艺术》第二部分：保留作者路线和反例

当前中译待校 PDF 245–589 页把 24 个动作放进四个松散阶段；它们不是本技能的 Phase 0–5，也不是经验证的因果序列。下表提炼**可按事实触发的问题**，保留原书叙事与可用动作的差别。

| 作者阶段与页段 | 有事实触发时可取的问题与动作 | 书内反例／停止点 |
| --- | --- | --- |
| 引起兴趣，PDF 248–342 | 若双方自愿交流，先看真实互动与目标是否相容；可呈现本人真实的多面兴趣、轻松话题和明确意图。 | 第 1–8 动作含寻找脆弱对象、假朋友身份、假偶遇、制造竞争、批评不安全感等；故事多为小说或作者解释。脆弱和拒绝都不是推进机会。 |
| 制造新鲜感，PDF 342–443 | 已有共同兴趣时，可给知情且能拒绝的小惊喜，注意对方真正提过的细节；真实日程与自然独处不需伪装。 | 第 9–15 动作也主张假身份、故意缺席、假装脆弱和隔离支持网络；PDF 354、399、412–413、443 页各有厌烦、注意转移或恐慌的反例，不设“撤回必然吸引”。 |
| 加深影响，PDF 443–525 | 双方愿谈时，兑现承诺、提供真实可持续的帮助；艺术、活动或理想话题只按双方确有兴趣分享。 | 第 16–20 动作混入制造危机、探童年伤痛、禁忌与痛苦循环；作者 PDF 524 页也承认痛苦会使人离开。不给人制造依赖或拿历史故事当个案心理证据。 |

## 分歧与缺口

- 《米豪方法》的“友好回应要接住”与故意引发嫉妒／冷处理并存；《让她神魂颠倒》赞成直接表达兴趣，反对机械延迟回复。按本案事实选真实、可撤回的动作，不把任一本的效果说成已验证。
- 《泡学惯例军火库》一面承认过度打压会伤人，一面收录侮辱脚本；可迁移的是双方都接受的轻玩笑及反馈修复，原脚本不作为推荐话术。
- 当前《米豪方法》有图示缺失和错行；《把妹达人圣经》为合订译本，原版对应关系未校。不能补造图义、原句或具体章节名。
