# xiaonanhai

面向成年男性求助者的沟通与证据分析技能：将事实、推测、未知分开，结合当前目标给出行动、三个不同角度的候选回复、唯一首选与停止条件。覆盖私人关系及商务沟通；不保证吸引、关系或交易结果。

## 使用

- 支持 SKILL.md 的工具：下载仓库，将整个目录作为技能安装，保留 `references/` 的相对结构，并按宿主的技能入口启用。
- 支持附件或知识文件的聊天工具：先加载 [SKILL.md](SKILL.md)，再按 [索引](references/index.md) 提供当前场景所需条目。只加载入口却没有所需参考文件时，模型须说明知识缺口。
- 手机与电脑使用同一套 Markdown。不同模型与应用的文件、上下文和自动触发能力不同；本仓库不会自动安装到其他应用，也不自动联网读取私人资料。

可以这样开始：“按 xiaonanhai 分析以下虚构对话，先区分事实和推测，再给三个角度并选一个首选。”

## 数据与内容范围

仓库只含技能规则、精炼知识和虚构示例。对话、截图、OCR、缓存、个人档案、令牌及原书不属于此仓库；使用时不得将个案提交为 Issue、PR、日志或训练样本。云端模型读取用户输入仍由该平台处理，本技能不提供离线保证。

私有原书不是依赖项。仅持有人明确授权的本地文件可供当次核对，公开使用者无法通过此技能取得私库访问权。不得公开私人路径、链接或摘录。知识出处与未完成范围见[来源说明](references/sources.md)。

## 维护与许可

新增公开文件必须同步维护 `PUBLISH_ALLOWLIST.txt` 并逐项审查。保留事实驱动流程与来源限制，不将单人习惯升级为通用规则。提交示例须为虚构情境，不用真实个案脱敏后冒充虚构。
